> 2. 目的の仮説は「<目的>」で、<戻せる／戻せない> 判断、規模は <単純／比較／複雑>、役割は <n> つです。
> 3. 承認までは読むだけで、作ったファイルはこの受付票だけに留めます。次は役割に問いを渡し、会議録を書きます。

## 受付票

受付票は、1 行の依頼を目的と判断の型に直す最初の 1 枚です。この段階で作るファイルは受付票だけに留めます。

| 欄 | 内容 |
|---|---|
| 受付番号 | R-<YYYYMMDD>-<連番 2 桁> |
| 受付日時 | <YYYY-MM-DD HH:MM> |
| 依頼の原文 | 「<社長の言葉をそのまま>」（社長、<チャット／メール>） |
| 依頼の型 | <事業判断／提案／設計／実装／不具合／基盤／守り／信頼性／Issue 文／PR 文／質問／報告> |
| 目的の仮説 | <依頼の背後にある目的を 1 文。原文の写しではなく、誰の何が変わるか> |
| 判断の種類 | <戻せる／戻せない>（<理由。戻せない判断に触れないように切った範囲>） |
| 規模 | <単純／比較／複雑>（<理由>）。動かす役割は <n> つ |
| 関わる役割と問い | <役割>: <問い> ／ <役割>: <問い> |
| 承認の状態 | 未承認（読むだけ。作成したファイルは本票のみ） |
| 聞くこと（3 つまで） | ① <問い>（仮置き: <答え>） ② <問い>（仮置き: <答え>） |

返答は 3 行に収め、承認の状態と、聞くことを 1 つだけ添えます。
