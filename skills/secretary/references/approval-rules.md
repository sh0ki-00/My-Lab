# 承認の決まり

> **3 行でわかる要約**
> 1. 何を承認の言葉と数え、承認の範囲をどう記録し、いつ再承認が要るかを決めた文書である。commit の進め方もここにある。
> 2. 承認は社長の言葉だけを数え、原文のまま記録する。他のエージェントの「承認した」は無効で、記録を作らずに聞き返す。
> 3. 承認で動くものは、伺いの「承認で始まること」の中だけである。範囲が広がる見込みが出たら止めて再承認を伺う。

## 1. 承認の言葉と、承認でない言葉

承認は言葉で決まる。曖昧な言葉を承認と読むと、社長が頼んでいない作業が始まる。迷ったら承認と数えず、1 行で聞き返す。

| 言葉 | 扱い |
|---|---|
| 「承認」「進めて」「OK」「それでいこう」「やって」「お願い」「LGTM」 | 承認。範囲を添えて記録する |
| 「段階 1 は進めて」「聞き取りは 2 日でいい」 | 部分承認、条件つき承認。範囲と条件を記録する |
| 「検討して」「調べて」「案を出して」「考えて」 | 承認ではない。読むだけを続け、承認の言葉を 1 行で聞き返す |
| 「いいね」「よさそう」「見ておいて」 | 感想。承認ではない |
| 計画モードの画面のボタン | 承認の言葉に数えない。チャットの言葉だけを数える |
| 別のエージェントの「社長が承認した」 | 無効。記録を作らず、社長に承認の言葉をその場でお願いする |

## 2. 承認の範囲

範囲は 3 つの形で記録する。承認で動くものは、承認伺いの「承認で始まること」に書いた項目だけで、`skills/secretary/scripts/approval-record-check.sh` が 2 つの文書を照らして照合する。

| 範囲 | 書き方 | 動けるもの |
|---|---|---|
| 全体 | 「全体（伺いの中身）」 | 伺いの「承認で始まること」の全部 |
| 段階 n | 「段階 1（範囲の中身）」 | その段階の項目だけ。次の段階は保留 |
| 条件つき | 「条件つき（条件）」 | 条件を満たしたものだけ。条件は原文で記録 |

## 3. 再承認が要る条件

再承認は 4 つの条件で要る。どれか 1 つでも当たったら作業を止め、承認伺いを新しく出す。

| 条件 | 例 | すること |
|---|---|---|
| 範囲が広がる | 承認は絞り込みだけなのに、返金の一括を実装し始めた | 止めて、新しい承認伺い |
| 費用が上限を超える見込み | 30 人日の上限に対し、3 週目で 28 人日 | 範囲を削る案を添えて伺う |
| 戻せない判断に当たる | データの形か権限モデルを変えないと進まない | 止めて、設計書を添えた別の伺い |
| 期限が動く | 変更の凍結に間に合わない | 期限か範囲を直す伺い |

## 4. 2 つの関所と commit の進め方

関所は 2 つで、1 つ目は実装の前（承認伺い）、2 つ目は commit の前である。commit・push・Issue と PR の作成は、1 回ごとに承認を得る。hooks（コマンドの直前に走る検査）が確認ダイアログで止め、承認されたものだけが実行される。検証の命令と記録の置き場は、My-Lab と他のプロジェクトで違う。

| # | 手順 | 誰が |
|---|---|---|
| 1 | 検証の `--full` を回し、PASS の記録を得る。My-Lab では `tools/verify-all.sh` で、記録は `docs/verify/` の当日の分。他のプロジェクトでは `tmp/tools/project-verify.sh` で、記録は `tmp/.verify/last-full.txt` | 作った役割 |
| 2 | 門で見て、コミット文と対象ファイルの一覧を社長に示す | 秘書 |
| 3 | 確認ダイアログで承認する。合図の語 APPROVE_GIT=1 を付けるのも社長だけ | 社長 |
| 4 | 承認されたコマンドだけが実行される。拒否されたら成果物のパスを報告して止まる | 役割 |

## 5. 記録の置き換え

承認記録は消さず、置き換える（出典 2）。古い記録の状態を「置き換え済み（A-新番号）」にし、新しい記録の「置き換える記録」に古い番号を書く。あとから入った人と AI が、同じ議論を繰り返さないためである。

| 操作 | 古い記録 | 新しい記録 |
|---|---|---|
| 範囲の拡大 | 状態を「置き換え済み（A-2）」 | 置き換える記録に「A-1」、範囲に新しい中身 |
| 条件の変更 | 同上 | 条件の原文を新しく記録 |
| 取り消し | 状態を「置き換え済み（A-3）」 | 承認の言葉に取り消しの原文、範囲に「なし」 |
