# 構成と動かし方: messy-shop

> **3 行でわかる要約**
> 1. messy-shop の言語、DB、動かし方、試験を、根拠つきで並べた節です。
> 2. このアプリは python と sqlite だけで動きます。サーバーは無く、画面はルートの表から処理を引きます。
> 3. 試験が無いので、変えたあとの確かめ方は依頼ごとに決めてください。

## 1. 構成

コードは app/ の 1 つのディレクトリにまとまり、言語の版はどの設定ファイルにも書かれていません。DB は sqlite の 1 ファイルで、置き場は環境変数で変えられます。

| 項目 | 内容 | 根拠 |
|---|---|---|
| 言語 | python 14 本と、マイグレーションの SQL 4 本 | F-005、F-006 |
| 言語の版 | 設定ファイルに書かれていない | F-009 |
| ディレクトリ | app/ に 19 本。直下にコードは無い | F-007、F-008 |
| DB | sqlite。置き場は環境変数 SHOP_DB で、無ければ app/shop.db | app/config.py:4、F-042、F-044 |
| DB を開く所 | db.conn() が 1 本の接続を持ち回る | app/db.py:10-15 |
| 書き込み | db.exe() が 1 文ごとに commit する | app/db.py:31-34 |
| マイグレーション | app/migrations/ の SQL 4 本。流すコマンドは設定に無い | F-043、F-010 |
| 時刻 | db.jst_now() は、名前と違って協定世界時を返す | app/db.py:18-20 |
| 設定の値 | 税 10%、送料 600 円、税込み 5,000 円以上で送料無料 | app/config.py:8-10 |

## 2. 動かし方

サーバーの仕組みはこのリポジトリに無く、画面は views.handle() がルートの表から処理を引きます。夜の処理と集計は、python のコマンドで回します。

| すること | コマンドか呼び方 | 根拠 |
|---|---|---|
| 画面を出す | views.handle() にルートと引数を渡す | app/views.py:179-183 |
| 夜の処理 | python3 jobs.py の後ろに処理の名前（stats、stock_alert、carrier） | app/jobs.py:1、F-036 |
| 毎週のメール | python3 mail_report.py weekly。月曜の朝に cron が回す | app/mail_report.py:33-37、F-038 |
| 年の集計 | python3 reports.py の後ろに年。年に 1 回、手で回す | app/reports.py:3、F-039 |
| cron の設定 | サーバーにあり、このリポジトリには無い | app/MEMO.txt:9 |

## 3. 試験

試験のファイルは 0 本で、回せる試験がありません。キャッチアップ（作業の前に掴むこと）では、何も回していません。

| 項目 | 内容 | 根拠 |
|---|---|---|
| 試験のファイル | 0 本 | F-011 |
| 起動とテストのコマンド | 設定に書かれていない | F-010 |
| 回した結果 | 回していない（回す試験が無い） | F-011 |
