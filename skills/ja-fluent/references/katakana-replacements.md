# カタカナ語の言い換えと、残してよい技術用語

> **3 行でわかる要約**
> 1. 技術文書に出るカタカナ語 40 語の言い換え表と、言い換えずに残してよい技術用語の一覧です。
> 2. 根拠は国立国語研究所『「外来語」言い換え提案』（176 語）と、文化庁『公用文作成の考え方』の外来語の扱いです。
> 3. 言い換え表の語は `scripts/katakana.txt`、残す語は `scripts/allow-katakana.txt` にあり、`fluency-check.sh` が読みます。

## 1. 言い換える語

読み手が社長や新人のときは、左の語を右の語にします。文の意味が変わるときは、左の語を残して括弧で説明します。

| カタカナ語 | 言い換え | カタカナ語 | 言い換え |
|---|---|---|---|
| アクセス | 接続、利用 | パフォーマンス | 性能 |
| アジェンダ | 議題 | フィードバック | 意見、感想 |
| アウトプット | 成果、出力 | プライオリティ | 優先順位 |
| インフラ | 基盤 | プロセス | 過程、手順 |
| インプット | 入力、材料 | ベンダー | 納入業者 |

## 2. 残してよい技術用語

日本語で言い換えると遠回りになる語です。初出で括弧の説明を付けて残します。

| 残す語 | 初出の説明の例 |
|---|---|
| キャッシュ | 一度取った結果を取っておく仕組み |
| サーバー、ブラウザ、データベース、ネットワーク、クラウド | 一般に通じるので説明は省いてよい |
| リポジトリ、コミット、ブランチ、マージ、プルリクエスト | git の語。初出で「変更の記録」「取り込み」などを添える |
| デプロイ、リリース、ロールバック | 本番に出す、前の版に戻す |
| ログ、エラー、テスト、バックアップ、バージョン | 一般に通じる |
| トークン、セッション、クッキー | 認証の語。初出で説明する |
| オフセット、カーソル、インデックス | 技術用語として残し、索引など日本語で言える語は日本語に |
