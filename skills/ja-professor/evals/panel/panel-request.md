# 判定者への依頼文

別コンテキストの判定者に、下の「ここから」と「ここまで」の間をそのまま渡します。解説のファイルの場所だけを足します。

## ここから

あなたは判定者です。この分野を初めて学ぶ新人の立場で、3 本の解説を読み、採点してください。書いた人の意図や経緯は知らないものとして扱い、甘くせず厳しく採点してください。5 は完璧なときだけ付けます。

読むものは 3 本で、それぞれ「解説」の節だけを読み、他の節は読みません。

| 解説 | ファイル | 読む節 |
|---|---|---|
| 1 | `skills/ja-professor/examples/example-n-plus-one.md` | 「## 3. 教授の解説」 |
| 2 | `skills/ja-professor/examples/example-index.md` | 「## 2. 解説」 |
| 3 | `skills/ja-professor/examples/example-hooks.md` | 「## 2. 解説」 |

各解説について、次の 4 つを出してください。

- (a) 言い直し。解説に書いてあることだけを使い、3 文で自分の言葉で言い直します。
- (b) 事実の有無。下の表の 3 つの事実のうち、言い直しに含まれているものを番号で書きます。
- (c) 採点。A から E を 1〜5 の整数で付けます。
- (d) 一番分かりにくかった所を 1 行で書きます。

| 観点 | 問い |
|---|---|
| A | 問いに先に答えているか |
| B | 新人として理解できたか |
| C | 用語が初出で説明されているか |
| D | 例が業務の場面で分かりやすいか |
| E | 読み手が次にすることが分かるか |

| 解説 | 事実 ① | 事実 ② | 事実 ③ |
|---|---|---|---|
| 1 | 注文ごとに 1 件ずつ取るから 1 + N 回（50 件で 101 回）になる | 会員と商品を ID の一覧でまとめて取ると 3 回になる | 件数が増えても回数は変わらない |
| 2 | 索引があると全件を見ずに該当する行へたどれる | 索引は列ごとに作るので、受注日時の索引は顧客名の検索には効かない | 書き込みは少し遅くなる |
| 3 | hooks はコマンドの直前と編集の直後に自動で走る検査 | 判定本体が「確認」を返すと、社長が承認するまでコマンドは走らない | 止めているのは AI の約束ではなく道具の仕組みで、文字列だけを見るので万能ではない |
