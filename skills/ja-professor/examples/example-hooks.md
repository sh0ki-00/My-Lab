## 2. 解説（Claude Code の端末向けの回答）

社長

ご質問は 2 点ですね。(1) hooks とは何か、(2) なぜ AI の commit を止められるのか、です。hooks は初めて出る語なので、その場で括弧で説明し、下の用語の表にもまとめました。

### 答え

(1) hooks（フック。コマンドの実行の直前と、ファイルを直した直後に自動で走る小さな検査）です。Claude Code と Cursor のどちらにもあります。(2) 止められるのは、AI が `git commit`（変更の記録を残す操作）を実行する前に hooks が割り込み、「確認」を返すからです。確認が出ると、社長が承認するまでコマンドは走りません。

### 全体像

commit の 1 回の流れを、誰が何をするかの順で並べます。

| 順 | 誰が | 何をする |
|---|---|---|
| 1 | AI | `git commit -m "..."` を実行しようとする |
| 2 | Claude Code か Cursor | 実行の前に hooks を呼び、コマンドの文字列を渡す |
| 3 | hooks の判定本体（文字列を見て判定を返す部分） | 「許可」「確認」「拒否」のどれかを返す。commit は「確認」 |
| 4 | 社長 | 確認の画面で承認するか、止める |
| 5 | AI | 承認があれば実行し、無ければ成果物のパスを報告して止まる |

### 用語

この回答で出た語は 2 つです。意味と正式な語を並べます。

| 用語 | 意味 | 正式な語 |
|---|---|---|
| hooks | コマンドの直前と編集の直後に自動で走る検査。両ツールの設定ファイルに登録する | hooks |
| 判定本体 | コマンドの文字列を受け取り、許可・確認・拒否を返す 1 本のスクリプト | `hooks/guard-core.sh` |

### 仕組み（なぜ止められるのか）

AI は、コマンドを自分で直接は実行しません。Claude Code や Cursor という道具に「このコマンドを実行して」と頼みます。道具は実行の前に hooks を呼ぶので、hooks が「確認」と返せば、道具は社長の承認を待ちます。つまり止めているのは AI の心がけではなく、道具の仕組みです。AI が「承認なしに commit しない」と約束するだけなら破れますが、hooks は約束ではなく機械で止めます。

hooks を入れれば何でも止まるわけではありません。判定本体が見るのはコマンドの文字列なので、`git commit` を別の名前のスクリプトに包めば見逃します。だから My-Lab では守りを 2 重にしています。1 つ目が hooks、2 つ目が Claude Code の設定ファイル（`.claude/settings.json`）に書いた承認の規則で、hooks が見逃してもこちらが確認を出します。そのうえで、AI の側の決まりでも禁じています。

### 例（実測）

例えば、AI が「検証が通ったので commit します」と言って `git commit` を打つと、確認の画面が出ます。社長が承認を押すまで、変更の記録は 1 行も増えません。判定本体が返す判定を、よく使う操作で並べると次のとおりです。

| 操作 | 判定 | 社長の手間 |
|---|---|---|
| `git status`、`git diff` | 許可 | 無し |
| `git commit -m "..."`、`git push` | 確認 | 承認の 1 回 |
| `git reset --hard`（作業の破棄） | 確認 | 承認の 1 回 |

### 確かめ方（手順）

手元で確かめる手順は 3 つです。

1. `bash hooks/selftest.sh` を実行します。これは、承認が要る操作と通してよい操作の見本 158 件を流し、判定どおりに返るかを機械で確かめる試験です。`RESULT: PASS hooks の自己試験 158 PASS / 0 FAIL` が出れば、判定は正しく動いています。
2. Claude Code に「`git status` を実行して」と頼みます。止まらずに結果が出ます。
3. Claude Code に「commit して」と頼みます。確認の画面が出て、承認しなければ実行されません。

### 確認の問い

一つだけ教えてください。この説明で一番分かりにくかった所はどこでしょうか。次の説明はそこから始めます。

次にしていただくことは 1 つです。最初の commit を承認するときに、手順 3 の確認の画面が出ることを一緒に見てください。
