# 用語の表（見出しに「用語」を含む節の表）に載る語、括弧の説明が付いた語、読み手の記録で「知っている語」の語は説明済みと見る。
N+1	一覧を取ったあと、行ごとに 1 回ずつ問い合わせる作り
ORM	プログラムの部品とデータベースの表を対応づける道具
SQL	データベースに頼むための言葉
API	画面と記録をつなぐ窓口
JSON	データを文字で表す形式
HTTP|HTTPS	ブラウザとサーバーのやりとりの決まり
キャッシュ	一度取った結果を取っておく仕組み
索引|インデックス	条件に合う行を速く探す仕組み
結合|JOIN	2 つの表を 1 回の問い合わせでつなげること
遅延読み込み|lazy loading	関連する行を使う瞬間まで取りに行かない動き
まとめ読み|eager loading	関連する行を先に 1 回で取っておく動き
問い合わせ|クエリ	データベースに「この条件の行をください」と頼むこと
トランザクション	まとめて成功か失敗かを決める一連の処理
マイグレーション	データの形や置き場を移す作業
デプロイ	作ったものを本番に出すこと
ロールバック	前の状態に戻すこと
冪等	同じ操作を何度しても結果が同じこと
ページング|ページネーション	一覧を何件かずつ区切って見せること
カーソル方式	「この注文の次から」と覚えて次のページを取る方式
オフセット方式	「何件目から」と数えて次のページを取る方式
メトリクス	数で測った状態の記録
トレース	1 つの処理が通った道筋の記録
SLO	守ると決めた信頼性の目標
SLI	信頼性を測る指標
エラーバジェット	許容する失敗の量
バーンレート	許容する失敗を使う速さ
Runbook	当番の手順書
IaC	インフラをコードで作る仕組み
Terraform	インフラをコードで作る道具
Docker	アプリを箱に詰めて動かす道具
コンテナ	アプリと土台をまとめた箱
Kubernetes	コンテナを並べて動かす仕組み
CI/CD	自動の検査と自動の配備
hooks|フック	コマンドの直前と編集の直後に走る検査
Lighthouse	Google の性能測定
axe	アクセシビリティ検査
Playwright	ブラウザの自動操作
shellcheck	シェルの静的検査
gitleaks	秘密の検出
trivy	依存の既知の穴の検出
semgrep	コードの静的検査
frontmatter	ファイル冒頭の名前と説明の欄
Mermaid	文字で図を描く記法
リポジトリ	変更の記録をまとめた置き場
ブランチ	変更の枝分かれ
マージ	枝分かれを取り込むこと
プルリクエスト|PR	差分をレビューしてもらう依頼
リベース	枝分かれの土台を付け替えること
コンフリクト	同じ所を別々に変えた衝突
トークン	認証の印
セッション	ログインしている状態の記録
クッキー	ブラウザに置く小さな記録
CSRF	利用者になりすまして操作させる攻撃
XSS	画面に悪いスクリプトを差し込む攻撃
認可	誰に何を許すかの判定
認証	本人かどうかの確認
ハッシュ	元に戻せない形に変えた値
暗号化	鍵が無いと読めない形に変えること
レプリカ	同じ中身の写し
スロークエリ	時間のかかる問い合わせ
レイテンシ	1 回の処理にかかる時間
スループット	一定時間に処理できる量
p99	100 回のうち遅い方から 2 番目の値
全件走査	表の行を最初から最後まで全部見ること
