# 演出計画書: <件名の見せ場>

> **3 行でわかる要約**
> 1. <前の場面> から <次の場面> へ移る見せ場「<動きの語彙>」の演出計画書です。数値は <架空／実測> とします。
> 2. 初回は <N>ms、2 回目以降は <N>ms です。共有要素は <部品> で、<前の場面> から <次の場面> まで付いて来ます。
> 3. フロントエンドは時刻ごとの表とトークンのとおりに作り、100ms ごとのフレームを撮って監修に出してください。

| 項目 | 内容 |
|---|---|
| 画面の型 | 没入の型 |
| 演出 ID | `<scene-前の場面-次の場面>` |
| 区分 | 見せ場 |
| 場面 | <前の場面（画面）> から <次の場面（画面）> へ |
| 長さ | 初回 <N>ms、2 回目以降 <N>ms |
| 共有要素 | <部品の名前>。<前の場面で何で、次の場面で何になるか> |
| 動きの語彙 | <世界観の設定の動詞> |
| デザイン計画書 | <パス> |

演出計画書は、没入の型の見せ場ごとに 1 本書きます。移動と応答の動きは、デザイン計画書の動きの表に書きます。見せ場は次の 5 つの条件を満たすものだけを通し、検査は `motion-plan-check.sh` です。

| 条件 | 中身 |
|---|---|
| 段が 3 つ | 入り（押した合図）、見せ場（場面が動く）、収まり（部品が落ち着く） |
| レイヤーが 3 つ以上 | 奥・中・手前が、違う速さか違う時刻で動く |
| 共有要素が 1 つ | 前の場面の部品が、次の場面まで付いて来る |
| 動きが重なる | 前の動きが終わる前に、次の動きが始まる組が 1 つ以上ある |
| 守りが 5 行 | 動きを減らす設定、飛ばす手段、2 回目以降、アセットが間に合わないとき、終わりのフォーカス |

## レイヤー

レイヤーを奥から手前へ並べ、作り方を決めます。文字と入力は必ず DOM に置き、演出が重くても読めて打てるようにします。

| レイヤー | 奥行 | 対象 | 作り方 |
|---|---|---|---|
| <レイヤーの名前> | <奥> | <背景、光など> | <canvas 1 枚> |
| <レイヤーの名前> | <中> | <場面の題など> | <DOM> |
| <レイヤーの名前> | <手前> | <入力欄、ボタン、共有要素> | <DOM> |

## 時刻ごとの表

押した時刻を 0ms とし、動きを始まりの順に 1 行ずつ書きます。レイヤーと対象の欄は、レイヤーの表の名前で書き始めます。長さはトークンの表の値だけを使い、トークンの長さとずらしはフィボナッチの数列の値にします（`skills/designer/references/systems.md` の 7 節）。始まりの時刻と合計は足し算で決まるので、数列に当てません。

| 時刻 | 段 | レイヤーと対象 | 変化 | 長さと曲線 | 伝えること |
|---|---|---|---|---|---|
| 0ms | 入り | <共有要素のレイヤー> | <押した合図> | <89ms、標準> | <押せた> |
| <Nms> | 見せ場 | <奥のレイヤー> | <場面が動く> | <Nms、去る> | <伝えること> |
| <Nms> | 見せ場 | <共有要素のレイヤー> | <次の場面へ付いて来る> | <Nms、標準> | <同じ物が続く> |
| <Nms> | 収まり | <手前のレイヤー> | <部品が落ち着く> | <Nms、着く> | <着いた> |
| <Nms> | 収まり | <手前のレイヤーの入力欄> | <フォーカスが入る> | 0ms | <次の操作> |

## 守りの表

代わりの版と手段を、演出ごとに必ず書きます。上の 5 行が見せ場の条件で、下の 3 行は没入の型で足す守りです。上の 5 行に「なし」は書けず、止める操作と消音の操作は名前で書きます。

| 条件 | 版と手段 |
|---|---|
| 動きを減らす設定 | <位置と大きさを動かさない版。溶け込みの長さ（144ms など数列の段）と、終わりの状態> |
| 飛ばす手段 | <どのキーとどこを押しても、すぐ最後の状態へ進む。先に打った字を失わない> |
| 2 回目以降 | <600ms 以下の短い版（377ms など数列の段）。残す動き> |
| アセットが間に合わないとき | <押してから 100ms 以内に必ず動く物と、替える版> |
| 終わりのフォーカス | <フォーカスを入れる要素と、読み上げに伝える題> |
| 5 秒を超える動き | <止める操作の名前（「動きを止める」など）と置き場。5 秒を超える動きが無ければ「無い」> |
| 点滅 | <明るさの大きな切り替わりの回数。1 秒に 3 回まで> |
| 音 | <最初の版は音なし。入れるときは、消音の操作の名前と置き場。常に画面に置く> |

## トークン

時刻ごとの表の長さと曲線を、トークンの名前と値で持ちます。フロントエンドは、この名前のまま tokens.css に写します。

| トークン | 値 | 使う所 |
|---|---|---|
| `<--duration-名前>` | <Nms> | <どの拍か> |
| `<--ease-名前>` | <cubic-bezier(…)> | <標準／去る／着く／収まる> |
