# 監修の方法

> **3 行でわかる要約**
> 1. 実装された画面を計画書に照らして監修する方法を決めた文書である。5 観点（忠実度・AI らしさ・WCAG 2.2 AA・キーボード・動き）と、許容差と判定の 3 択を書く。
> 2. 計画が判定基準であり、感想で差し戻さない。値は機械で突き合わせ、指摘は場所・計画の値・実装の値・直し方・重さの 5 欄で書く。
> 3. 監修は実装した本人がしない。秘書が別のサブエージェント（別の文脈で動く補助の AI）か新しいチャットで回す。

## 1. 5 観点と道具

監修は 5 観点を順に見る。道具で測れるものは道具で測り、人の目は道具が拾えない所に残す。

| 観点 | 何を見るか | 道具 |
|---|---|---|
| 忠実度 | 計画書の色・ms・px とトークンと実装の値の一致 | `skills/designer/scripts/fidelity-check.sh` |
| AI らしさ | 既定の見た目の件数と帯 | `skills/designer/scripts/ai-look-check.sh --plan <計画書>` |
| WCAG 2.2 AA | 見た目側の 10 項目の実測 | `skills/designer/scripts/contrast-check.sh`、Tab の通し、DOM の寸法 |
| キーボード | 計画のキーの表の全行が動くか | 手で通す。Playwright（ブラウザ操作の自動テスト）があれば記録 |
| 動き | 場面ごとの ms、減らす設定、キーボード起点 | 画面を撮るか、DOM の transition の値を読む |

## 2. 突き合わせるものと許容差

値の突き合わせは許容差を先に決める。色は 0、px は ±2、ms は ±20 で、差の重さは場所で決める。

| 突き合わせるもの | 許容差 | 重さの決め方 |
|---|---|---|
| 名前つきの色、導出の色 | 0（16 進が一致） | 本文と地は高、補助と装飾は中 |
| 行高、ペインの幅、帯の高さ | ±2px | 密度に効く行高は高、帯は中 |
| 動きの時間 | ±20ms | 300ms 超か減らす設定の欠けは高、差だけなら低 |
| 角丸、影 | 段の数が一致 | 均一になっていれば中 |
| シグネチャ | 要素があり、伝える情報が出る | 無ければ高 |
| 焦点の枠 | outline で描き、2px 以上 | box-shadow だけなら高（強制カラーで消える） |

## 3. 手順

手順は 9 つで、終わりの印を持つ。撮れない環境では DOM の値で代える。

| # | 手順 | 終わりの印 |
|---|---|---|
| 1 | 計画書とトークンを読み、突き合わせる値の一覧を作る | 一覧がある |
| 2 | `fidelity-check.sh` で 16 進と ms を突き合わせる | 差の表がある |
| 3 | `ai-look-check.sh --plan` を実装に回す | 件数と帯がある |
| 4 | 5 状態ごとに画面を見る（撮れるなら撮る） | 5 状態 × 画面の表がある |
| 5 | AA を測る（比の計算、焦点、固定の帯、押せる領域、強制カラー） | 10 項目に値がある |
| 6 | キーボードで主要な用事を通す | キーの表の全行に結果がある |
| 7 | 動きを確かめる（ms、曲線、減らす設定、キーボード起点） | 動きの表の全行に結果がある |
| 8 | 指摘の表と判定を書く | 全指摘に 5 欄がある |
| 9 | `review-check.sh` と `tools/check-file.sh` を通し、秘書に返す | 両方 PASS |

## 4. 判定の 3 択

判定は 3 択で、条件には確認方法と期限を書く。感想の指摘（「もっとおしゃれに」）は書かない。計画書が無い画面は、先にデザイナーが計画を書いてから監修する。

| 判定 | いつ | 書くこと |
|---|---|---|
| 受け入れ | 差 0、帯 clean、AA の 10 項目が充足、キーと動きが全行一致 | 測った値 |
| 条件つき受け入れ | 重さ「中」以下の指摘だけ | 条件、確認方法、期限 |
| 差し戻し | 重さ「高」の指摘が 1 つ以上 | 指摘の表と直し方 |

## 5. 撮れない環境

Claude Code のデスクトップ版はブラウザの画面を撮れるが、Cursor は環境に依る。機械検査と DOM の値を必須にし、撮影は任意にする。

| 見たいもの | 撮れないときの代わり |
|---|---|
| 密度と配置 | 行高、ペインの幅、塊の数を px と個数で計画書と突き合わせる |
| 焦点の枠 | DOM の outline の値と、Tab で焦点が移る要素の一覧 |
| 動き | DOM の transition と animation の値、prefers-reduced-motion の分岐の有無 |
| 5 状態 | 状態ごとの DOM の文字列（空の文、エラーの 2 文） |
