# デザイン計画書: 注文一覧の伝票にメモ欄を足す

> **3 行でわかる要約**
> 1. 管理画面の注文一覧（samples/app）の伝票に、梱包の注意のためのメモ欄を足す計画書です。画面の型は既存に合わせる型で、依頼と日付は架空です。
> 2. 色・時間・大きさ・書体は、既存の UI の棚卸しの表にある値だけを使い、足す値は 0 件です。
> 3. フロントエンドは既存の tokens.css をそのまま使い、`fidelity-check.sh` に `--existing samples/app` を付けて PASS させてください。

| 項目 | 内容 |
|---|---|
| 画面の型 | 既存に合わせる型。材料は、直近 1 年の commit の作者が 3 人で、既存の UI のトークン（samples/app/tokens.css）があること。依頼者が受付で決めた（架空） |
| 作成日 | 2026-11-26 |
| 状態 | 完成例。既存の注文一覧に 1 つの欄を足すだけの計画 |
| 入力 | 受付票（架空）、既存の UI（samples/app）、棚卸しの表（この計画書の「既存の値」の節） |
| 置き場 | 本番の案件では tmp/flow/pane-memo/design-plan.md |
| 数列 | 数列の前の版（2026-11-27 より前）。値は見本アプリと実測につながるので、次の PR で数列に直す |

画面の型は受付票の欄を写したもので、デザイナーは選び直していません。既存に合わせる型では、新しい色を選ばず、既定との差も書きません。その代わりに、計画書の値が既存の値か「足す値」の表にあるかを検査で突き合わせます。

## 目的と対象

依頼は「伝票に、梱包の注意を書き残せる欄がほしい」の 1 行です。利用者は、毎朝その日の出荷を片付ける運営の担当で、注文一覧と伝票を行き来しながら作業するので、欄は伝票の中に置きます。

| 項目 | 内容（数値は架空） |
|---|---|
| 依頼 | 伝票に、梱包の注意を書き残せる欄がほしい（依頼者、2026-11-26） |
| 利用者 | 運営の担当 3 人。1 日に 120 件ほどの注文を出荷指示する |
| 片付けたい用事 | 割れ物や同梱の注意を、次に伝票を開いた人へ伝える |
| 今の画面の困りごと | 注意を別の表に書き、伝票と見比べている |
| 画面の仕事（1 文） | 伝票の中で注意を書き、次に開いた人がすぐ読めるようにすること |

## 方向

方向は、いまある伝票の欄に作りをそろえます。新しい見た目を足さず、伝票の明細と同じ線と字で、欄を 1 つ増やします。

| 項目 | 決めたこと |
|---|---|
| 主題 | 帳場の伝票に、手書きの注意を 1 行足す |
| 方向の名前 | 既存に合わせる |
| 素材と語彙 | 伝票の欄、明細の線、検索欄と同じ入力枠 |
| 取らない方向 | 新しい色、新しい角丸、付箋の黄色、新しい動き |
| 取る危険 1 つ | 欄が明細に溶けて見落とされる。欄の名前を太字にし、空のときは例文で用途を示す |

## 書体

書体は既存の 1 家族のままで、並びは既存の `--font-text` と同じです。この Mac には BIZ UDPGothic が無いので、並びの 2 番目の Hiragino Sans で描かれます。

| 役 | 書体 | 大きさと太さ | 使う場所 | 理由 |
|---|---|---|---|---|
| 欄の名前 | BIZ UDPGothic（既存の --font-text。並びは "BIZ UDPGothic", "Hiragino Sans", "Yu Gothic UI", sans-serif） | 14px、太さ 700 | 「梱包の注意」の欄の名前 | 伝票の明細の見出しと同じ字にする |
| 本文 | BIZ UDPGothic（既存の --font-text） | 14px、太さ 400 | 入力した字と例文 | 既存の検索欄と同じ字にする |
| 補助 | BIZ UDPGothic（既存の --font-text） | 12px、太さ 400 | 残りの字数 | 既存の補助の文字と同じ大きさにする |

## レイアウトと密度

欄は伝票の明細の下、出荷指示のボタンの上に 1 つだけ置きます。伝票の情報の塊は、明細・メモ・操作の 3 つのままです。

| 項目 | 値 | 理由 |
|---|---|---|
| 欄の高さ | 88px（既存の 44px の 2 段） | 2 行を書ける。既存の大きさの値から選んだ |
| 欄の幅 | 伝票の内側いっぱい | 明細の線とそろえる |
| 欄の上下の余白 | 上 16px、下 8px | 既存の --space-4 と --space-2 |
| 残りの字数 | 欄の右下。12px の補助の文字 | 書きながら上限が分かる |

## シグネチャ: 検印（既存）

この画面を記憶に残す要素は、既存の検印のままです。メモ欄は新しいシグネチャを持たず、検印より目立たせません。

| 項目 | 決めたこと |
|---|---|
| 形 | 既存の検印（直径 28px の朱の円）。メモ欄には足さない |
| 伝える情報 | 出荷指示を済ませた伝票であること（既存）。メモは字だけで伝える |
| 出る場所 | 既存のまま、伝票の検印の欄 |

## 動き

動きは既存の 3 段（80・120・180ms）だけを使い、新しい動きは足しません。

| 場面 | 時間と曲線 | 何を伝えるか | 動きを減らす設定のとき | キーボード起点のとき |
|---|---|---|---|---|
| メモ欄のホバーで枠が濃くなる | 80ms、標準 | 書ける欄であること | 0ms | 0ms |
| 焦点の枠が欄に移る | 120ms、標準 | 次に打つ所 | 0ms | 0ms |
| 上限を超えたとき、残りの字数の文が替わる | 180ms、標準 | 書きすぎたこと | 0ms | 0ms |

## キーボードと操作の型

メモは、マウスを使わずに書けます。伝票の中の Tab の順は、明細、メモ欄、出荷指示のボタンです。

| 操作 | キー | マウス | 型の出どころ |
|---|---|---|---|
| メモ欄へ移る | Tab と Shift+Tab | 欄を押す | ブラウザの既定 |
| 改行する | Enter | なし | textarea の既定 |
| 欄の中で行を移る | 上下の矢印 | 行を押す | textarea の既定 |
| 書いた内容を残す | 欄から焦点を外す（Tab） | 欄の外を押す | 既存の伝票の保存と同じ |

## 引き渡し

フロントエンドには、既存のトークンと、この計画書だけを渡します。足すトークンはありません。

| 渡す先 | 渡すもの | 受け取る側の確認 |
|---|---|---|
| フロントエンド | 既存の samples/app/tokens.css（足すトークン 0） | 計画書と tokens.css と実装の css を `fidelity-check.sh` に渡し、`--existing samples/app` を付けて PASS |
| フロントエンド | この計画書（欄の位置・字・動き） | 既存の検索欄と同じ部品の作りで書く |

## やらないこと

最初の版は、メモを書いて残すことだけに絞ります。

| やらないこと | 理由 |
|---|---|
| メモの色分けや付箋の見た目 | 新しい色を足すと、検印と要対応の札の強さの順が崩れる |
| メモの書式（太字・箇条書き） | 梱包の注意は 1〜2 行で足りる |
| 書いたときの動きの演出 | 既存に合わせる型なので、既存の 3 段の動きだけを使う |
