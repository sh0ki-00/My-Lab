# 常設の RoE: <プロジェクト名>

常設の RoE（交戦規則。攻撃してよい範囲と条件を決めた文書）は、プロジェクトごとに 1 回署名します。範囲が変わると、指紋が合わなくなり、道具が自分で止まります。攻撃の相手は、ソースコードから手元で起こしたアプリだけです。クラウドの環境・本番・第三者には、1 本も送りません。

| 項目 | 内容 |
|---|---|
| 作成日 | <日付> |
| 状態 | <署名待ち／署名済み> |
| 承認記録 | <A-番号> |
| 依頼者の言葉（原文） | 「<承認の言葉をそのまま>」 |
| 期間 | <始まりの日> 〜 <終わりの日>（仮置きは 1 年） |

## 機械の節

道具（`scripts/attack-run.sh`）は、この節を読みます。範囲の指紋は、targets・launch・downstream・limits・period から計算した短い値です。この節を署名のあとで書き換えると、指紋が合わなくなり、道具は 1 本も送らずに止まります。

```json
{
  "targets": ["127.0.0.1"],
  "launch": "<アプリを手元で起こす命令>",
  "downstream": [
    {"name": "DB", "where": "<in-memory／disposable／127.0.0.1>", "mode": "disposable"},
    {"name": "mail", "where": "mock"},
    {"name": "external-api", "where": "mock"}
  ],
  "limits": {"per_handle": 60, "concurrent": 1, "per_request_timeout": 3, "total_timeout": 120, "max_total": 2000},
  "period": {"from": "<始まりの日>", "to": "<終わりの日>"},
  "approval_record": "<A-番号>",
  "requester_quote": "<承認の言葉をそのまま>",
  "fingerprint": "<targets・launch・downstream・limits・period から計算した sha256>"
}
```

## 範囲

範囲は、対象と宛先と写しの置き場です。宛先は 127.0.0.1 だけにします。所有の確認は、対象が依頼者の持ち物であることを示す証拠です。

| 対象 | 宛先 | 写しの置き場 | 所有の確認 | 試してよいこと |
|---|---|---|---|---|
| <ソースコードから起こしたアプリ> | http://127.0.0.1:<ポート> | <写しのディレクトリ/> | <対象の持ち主を示す証拠> | <表の手口 A01〜A12> |

## 下流

下流は、アプリがつなぐ先です。手口を送る前に、どれも手元・作り物・使い捨てであることを確かめます。手元でない宛先が 1 つでもあれば、道具は止まります。

| つなぐ先 | 手元か作り物か | 止めるか |
|---|---|---|
| DB | <使い捨てのテストデータ> | <起動のたびに作り直す> |
| メール | <モック（本物の代わりの作り物）> | <送らない> |
| 外部 API | <モック> | <つながない> |
| 保存先 | <使い捨てのディレクトリ> | <試験のあとに消す> |

## データ

データは、攻撃用の使い捨てです。作り直す命令を書きます。攻撃用の利用者は、役割ごとに 1 人と、別の持ち主を 1 人置きます。

| 種類 | 名前 | 作り直す命令 |
|---|---|---|
| 使い捨てのデータ | <名前> | <命令> |
| 攻撃用の利用者 | <役割ごとに 1 人、別の持ち主 1 人> | <起動のたびに作る> |

## 1 回の上限

上限は、機械の節の limits に書いた値です。送る本数・同時の本数・1 本と全体の打ち切りを、道具がそこから読みます。

## 止める条件

次のどれかに当たったら、道具は 1 本も送らずに止まります。

| 止める条件 | 中身 |
|---|---|
| 指紋が合わない | 署名のあとで機械の節を書き換えた |
| 宛先が手元でない | 127.0.0.1・localhost・::1 のほかに送ろうとした |
| 下流が手元でない | アプリの接続先に、手元でない宛先がある |
| 待ち受けが違う | そのポートで待つプロセスが、起動の命令で立った物でない |

## やらないこと

やらないことを先に書き、読み手が勝手に補わないようにします。

| やらないこと | 理由 |
|---|---|
| 本番と、第三者の持ち物への攻撃 | 対象は、ソースコードから手元で起こしたアプリだけ |
| クラウドの環境への攻撃 | 攻撃の相手に含めない。インフラは開発環境で、承認を得て扱う |
| 負荷をかけて止める試験 | 止める試験はしない |
| 使い捨てでない外のデータを消す試験 | データを消す試験はしない |

## 再署名が要る出来事

次のどれかが起きたら、新しい RoE に署名し直します。範囲か下流の表が変わる。手元の外の環境を足す。破壊的な試験を足す。
