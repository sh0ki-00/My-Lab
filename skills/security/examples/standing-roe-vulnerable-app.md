## 1. 機械の節

道具（`scripts/attack-run.sh`）は、この節を読みます。範囲の指紋は、targets・launch・downstream・limits・period から計算した値です。

```json
{
  "targets": ["127.0.0.1"],
  "launch": "python3 skills/security/evals/vulnerable-app/app.py",
  "downstream": [
    {"name": "DB", "where": "in-memory", "mode": "disposable"},
    {"name": "log", "where": "disposable"}
  ],
  "limits": {"per_handle": 30, "concurrent": 1, "per_request_timeout": 3, "total_timeout": 60, "max_total": 500},
  "period": {"from": "2026-11-26", "to": "2027-11-26"},
  "approval_record": "A-16",
  "requester_quote": "進めて",
  "fingerprint": "2773074e540f8bd643ba2dbeb0129a0000783d2b2d94fb20caf2bd5d6d07d90a"
}
```

## 2. 範囲

範囲は、対象と宛先です。宛先は 127.0.0.1 だけにします。所有の確認は、サンプルがこのリポジトリにある試験の的であることです。

| 対象 | 宛先 | 写しの置き場 | 所有の確認 | 試してよいこと |
|---|---|---|---|---|
| 試験の的のアプリ | http://127.0.0.1:<空きポート> | `skills/security/evals/vulnerable-app/` | このリポジトリにある試験の的 | 表の手口 A01〜A12 |

## 3. 下流

下流は、アプリがつなぐ先です。どれも手元か作り物なので、道具は止まりません。

| つなぐ先 | 手元か作り物か | 止めるか |
|---|---|---|
| DB | メモリの中の sqlite（使い捨て） | 起動のたびに作り直す |
| 保存先 | 使い捨てのディレクトリ | 試験のあとに消す |

## 4. 止める条件とやらないこと

止める条件は 4 つです。指紋が合わないとき、宛先が手元でないときに止まります。下流が手元でないときと、待ち受けが起動の命令と違うときも止まります。

やらないことは 3 つです。本番と第三者への攻撃はしません。クラウドの環境への攻撃と、負荷をかけて止める試験もしません。
