# SLO とエラーバジェットの決め方

> **3 行でわかる要約**
> 1. SLO 定義書の SLI・目標と期間・承認・エラーバジェットの扱い・リリースの可否を書くときの判断の表です。
> 2. 測り点は利用者に最も近い所に置き、承認者の無い SLO は出さず、残量を測るまで可否を返しません。
> 3. 定義書を書く前にこの資料を開き、書いたら slo-doc-check を通してください。

## 用語

この節は、資料に出る略語をまとめます。2 回目からは説明を省きます。

| 用語 | 意味 |
|---|---|
| SLO | 利用者に約束する信頼性の目標。目標の値と期間の組 |
| SLI | 目標を測る数。良い事象の数を有効な事象の数で割った割合 |
| エラーバジェット | 1 − 目標。期間のうちに失敗してよい量 |
| Runbook | 当番の手順書。通知 1 つに 1 本 |

## SLI の測り点

この節は、どこで数えるかの選び方です。利用者に近いほど、利用者が見た失敗をそのまま数えられます。API のプロセスのログだけで数えると、プロセスが落ちた時間の失敗が 0 件に見えます。

| 測り点 | 数えられる失敗 | 落とす物 | 使い方 |
|---|---|---|---|
| ブラウザ（利用者の端末） | 全部。網と画面の誤りも | 端末の差で揺れる | 画面の SLO。フロントエンドと決める |
| ロードバランサー | API が応えなかった要求も | 網の手前の失敗 | 既定の測り点 |
| 外形の確かめ（probe） | 決めた道の失敗 | 量の少ない失敗 | 要求の少ない時間の補い。見本ではこれが入口 |
| API のログ | API が返した失敗 | 落ちた時間、つながらない要求 | 原因を調べる材料。SLI にはしない |
| CPU やメモリ | 失敗ではない | 利用者の困りごと | 通知にも SLI にもしない |

有効な要求からは、利用者の側の誤り（形の誤り、権限の無い操作、無い資源）を除きます。除く理由と除かない理由（例: 正しい担当者に出ないはずの 401 は含める）を、定義書に 1 文で書きます。

## 目標と期間

この節は、目標の値と期間の決め方です。目標は、利用者が困り始める失敗の量から逆に決め、今の実力からは決めません。

| 決めること | 決め方 |
|---|---|
| 期間 | 30 日の転がる窓を既定にする。暦の月は月初に予算が戻り、月末の判断が甘くなる |
| 目標 | 1 段上げた場合と下げた場合に、利用者に何が起きるかを書いてから選ぶ |
| 予算の時間 | 全部が失敗したら何分で使い切るか（99.9% と 30 日なら 43.2 分）を添える |
| 数値 | 架空か実測かを冒頭の表に書く。実測は測った日と道具を添える |

## 承認

この節は、誰が約束を承認するかです。SLO は事業の約束なので、値を決める人の承認が無ければ出しません。

| 承認者 | 承認するもの |
|---|---|
| 事業の責任者 | 目標の値と、使い切ったときにリリースを止めること |
| サービスの持ち主（バックエンドなど） | 測り点と、止める役を担うこと |
| SRE | 測り方、通知、Runbook と訓練 |

承認の表には、承認者・立場・日付・判断の 4 列を置きます。slo-doc-check は、名前と日付と「承認」のそろった行が 1 つも無い定義書を落とします。

## エラーバジェットの扱い

この節は、予算の残りで何を変えるかの決め方です。予算は、機能を出す速さと信頼性を取引する量です。使い切ったときの決まりを先に承認しておくと、障害の最中に揉めません。

| 残り | 既定の決まり |
|---|---|
| 50% より多い | 機能のリリースを続ける |
| 0〜50% | 戻しを実測した変更だけを出す。出す前に Runbook の訓練を回す |
| 使い切った | 機能のリリースを止め、信頼性の処置だけを出す。再開の条件を決めておく |
| 測れていない | 可否を返さない。測り点を直すことを最初の処置にする |
| 1 件で 20% 以上を使った | 障害の記録を書き、処置に担当・期限・完了条件を付ける |

## リリースの可否

この節は、秘書の承認伺いに入れる可否の 1 行の書き方です。可否の根拠は予算の残量だけで、残量は測った値だけを使います。

| 状態 | 1 行の例 |
|---|---|
| 残量を測った（50% より多い） | 可。可用性の予算の残り 81%（2026-11-30 に測定） |
| 残量を測った（0〜50%） | 条件つきで可。戻しを実測した変更に限る |
| 使い切った | 否。信頼性の処置だけを出す |
| 測れていない | 返さない。測り点がそろう日を書く |
