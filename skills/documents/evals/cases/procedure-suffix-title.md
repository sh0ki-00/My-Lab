# My-Lab 全体の検証 手順書

| 項目 | 内容 |
|---|---|
| 作業名 | 全体の検証を回し、記録を残す |
| 対象システム | My-Lab（作業ブランチ） |
| 作業者 / 確認者 | 秘書 / 社長 |
| 承認 | 不要（読む操作と記録の書き込みだけ） |
| 版 | 1.0（2026-11-11） |

## 1. 目的

commit の承認を伺う前に、全体の検証を回し、記録を残す。FAIL があれば直してから回し直す。

## 2. 前提条件

- 作業ブランチにいる。
- 検証が呼ぶ道具が入っている（jq、node、python3、shellcheck ほか）。

## 3. 事前確認

| # | 確認項目 | 確認方法 | 期待結果 |
|---|---|---|---|
| 1 | ブランチ | `git branch --show-current` | main 以外が返る |

## 4. 作業手順

1. 全体の検証を回す。
   ```sh
   bash tools/verify-all.sh --full
   ```
   - 期待結果: `RESULT: PASS verify-all --full` で始まる行が出る。
2. 今日の記録が書かれたことを確かめる。
   ```sh
   ls docs/verify/ | tail -n 1
   ```
   - 期待結果: 今日の日付のファイル名が出る。

## 5. 切り戻し

1. 記録を残さない判断になったら、記録のファイルだけを戻す。
   - 期待結果: `git status --short` に `docs/verify/` の行が出ない。

## 6. 作業記録

```text
- 実施日時:
- 結果:
```
