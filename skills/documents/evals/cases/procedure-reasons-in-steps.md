# orders-admin 検査元 IP 許可 手順書

| 項目 | 内容 |
|---|---|
| 作業名 | 検査元 IP を WAF の許可リストに足す |
| 対象システム | orders-admin（本番） |
| 作業者 / 確認者 | インフラ役 / セキュリティ役 |
| 承認 | 依頼者（Issue のコメント） |
| 版 | 1.0（2026-11-11） |

## 1. 目的

脆弱性検査の送信元 IP を、検査の期間だけ WAF（通信を通すか止めるかを決める仕組み）の許可リストに足す。

## 2. 前提条件

- 検査元 IP の一覧を、依頼の Issue で受け取っている。

## 3. 事前確認

| # | 確認項目 | 確認方法 | 期待結果 |
|---|---|---|---|
| 1 | IP セットの名前 | `aws wafv2 list-ip-sets --scope CLOUDFRONT --region us-east-1` | `orders-admin-prod-office` が 1 件出る |

## 4. 作業手順

許可の正は IP セットである。IP セットに無い送信元は、既定の規則で止まる。

規則 rate-per-ip は 5 分に 2000 件で止めるので、検査元にも掛かる。

だから、検査会社には要求の上限を先に伝える。

1. 検査元 IP を IP セットに足す。
   - 期待結果: 差分が追加だけになる。

## 5. 切り戻し

1. 足した IP を外す。
   - 期待結果: IP セットが作業前と同じになる。
