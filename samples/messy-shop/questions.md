# messy-shop の 10 問

小さな通販「こもの屋」の管理アプリについての 10 問で、答えは渡された DB の中身で 1 つに決まります。管理アプリのコードと DB を読んで答えを出し、最後に JSON（決まった形の文字のデータ）で書いてください。

## 1. 前提

DB は、2026 年 11 月 1 日 0 時（日本時間）の時点の中身です。それより後の注文や変更は入っていないので、問いの「いま」はこの時点を指します。DB は読むだけにし、行を書き換えないでください。

| 項目 | 内容 |
|---|---|
| 渡すもの | 管理アプリのコード（app の写し）と、DB（sqlite のファイル） |
| DB の時点 | 2026-11-01 00:00（日本時間） |
| DB の扱い | 読むだけ。行を書き換えない |
| 答えの出し方 | 4 節の JSON の形で、10 問すべてに答える |

## 2. 言葉の決まり

問いの言葉は次の表の意味で読み、日付と月と年は、どの問いでも日本時間で区切ってください。

| 言葉 | 意味 |
|---|---|
| 期間の区切り | 注文を受けた日時で区切る。入金の日や出荷の日ではない。出荷を問う Q2 だけは、出荷した日で区切る |
| 注文 | お客様から受けた注文。お店の人が試しに入れた注文は、どの問いでも数えない |
| 会員 | お客様として登録した人。お店の人が試しに作ったアカウントは数えない |
| 会員番号 | 会員の表（customers）の id |
| 支払いが済んだ注文 | 代金を受け取った注文。発送の前か後かは問わない。キャンセルした注文と、まだ払われていない注文は入らない |
| 品物 | お客様が買った商品そのもの。送料は品物に数えない |
| 売上 | 支払いが済んだ注文の、品物の代金の税込みの合計。送料は含めない |
| キャンセル | お客様かお店が、注文を取り消したもの |
| 削除した注文 | 管理画面で消した注文 |

## 3. 問い

問いは 10 問で、答えの形は数・文字・一覧の 3 つです。数の問いには、正答と見なす誤差の幅を表の右の列に決めてあります。

| 番号 | 問い | 答えの形 | 許す誤差 |
|---|---|---|---|
| Q1 | これまでに受けた注文のうち、キャンセルになった注文は何件か | 数（件） | 0 |
| Q2 | 2026 年 9 月に出荷した注文は何件か | 数（件） | 0 |
| Q3 | これまでに削除した注文は何件か | 数（件） | 0 |
| Q4 | 2024 年の売上はいくらか | 数（円） | 正答の 0.1% まで |
| Q5 | 2025 年に売れた品物は、個数で合わせていくつか。支払いが済んだ注文の品物を数える | 数（個） | 0 |
| Q6 | 管理画面のトップにある月次の表は、2026 年 9 月の売上の欄にいくらと出しているか | 数（円） | 0 |
| Q7 | 2025 年の売上はいくらか | 数（円） | 正答の 0.1% まで |
| Q8 | 2026 年 8 月のうち、注文を一番多く受けた日はいつか。状態によらず、受けた注文を全部数える | 文字（YYYY-MM-DD の日付） | 完全に一致 |
| Q9 | 2026 年 10 月に買った金額の多い会員を、多い順に 3 人挙げよ。金額は、その月の支払いが済んだ注文の売上で比べる | 一覧（会員番号の整数を 3 つ、多い順） | 完全に一致。順も合わせる |
| Q10 | いま、お知らせのメールを受け取ると答えている会員は何人か | 数（人） | 0 |

Q6 だけは、2 節の言葉の決まりで数え直さずに、画面が表示している値をそのまま答えてください。

## 4. 答えの出し方

答えは、問いの番号が鍵の JSON 1 つで出してください。数は整数で書き、桁区切りと単位は付けません。

```json
{"Q1": 0, "Q2": 0, "Q3": 0, "Q4": 0, "Q5": 0, "Q6": 0, "Q7": 0, "Q8": "2026-01-01", "Q9": [1, 2, 3], "Q10": 0}
```

上の値は形を見せるための架空の値で、正答ではありません。問いごとに数えた SQL（DB への問い合わせの文）と結果も残してください。採点には使いませんが、外れた問いの原因をあとで確かめるときに読みます。
